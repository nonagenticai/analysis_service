# describes the IMPLEMENTATION's shape (how many calls, in what position)
# rather than what the code did.
#
# Enforced by tests/test_shape_only_test_guard.py
# (detector: scripts/check_vacuous_tests.py::find_shape_only_tests).
#
# This list is a ONE-WAY RATCHET: entries may only be REMOVED. A NEW shape-only
# test fails CI — fix the test, do not extend this file. When you fix one,
# delete its line here AND lower MAX_SHAPE_ONLY_TESTS to match.
#
# Regenerate the raw list with:
#     uv run python -m scripts.check_vacuous_tests --list-shape
#
# WHY THIS CLASS IS WORSE THAN NO TEST
# ------------------------------------
# It breaks on any CORRECT change and passes on any WRONG one that preserves
# the shape. On 2026-08-24/25, w2v-common 0.65.0 added one legitimate statement
# (REVOKE CONNECT ON DATABASE <db> FROM PUBLIC — the born-LOCKED provisioning
# policy) and reddened FIVE tests across FOUR sibling repos, none of which was
# asserting anything at all about database creation. The fix in every case was
# the same: replace the fixed-length side_effect list with a side_effect
# FUNCTION that RECORDS the statements, then assert over the recorded list
# (`assert any("CREATE DATABASE ..." in s for s in executed)`) instead of
# counting calls. See tts_service 0676f77 for the canonical shape.
#
# SOME ENTRIES BELOW ARE DEFENSIBLE, AND THAT IS THE POINT
# --------------------------------------------------------
# For a mock that stands in for an external EFFECT (close a client, cancel a
# task, re-scrape), "was it called" genuinely is the observable. A static
# checker cannot tell that apart from "I counted calls because I could not
# think of a property". So those land here with a stated reason — a reviewed
# exemption, not a silent hole in the detector. What the gate actually buys is
# that the NEXT one has to be argued for.
#
# Format: <repo-relative path>::<TestClass.>test_name   # reason
#
# Baseline 2026-10-05 (ported from w2v_orchestrator): generated by --list-shape;
# the trailing comment is the detector's reason, not a reviewed justification.
